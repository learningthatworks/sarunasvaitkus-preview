KINETIC

Type that moves. Letters stretch, squash, slide and react to scrolling or the cursor, so words carry rhythm and emotion before anyone reads them.

What defines it

Kinetic typography treats letters as moving objects. Variable fonts let one typeface change width and weight smoothly, which turns type itself into animation.

Variable axes

One font file changes width and weight continuously, so letters can breathe.

Rhythm and timing

Staggered delays turn a word into a wave or a beat.

Huge scale

Words fill the screen and act as the main image.

Responsive to people

Hover, scroll and cursor position change how the type behaves.

Where it came from

Moving type started in film titles and arrived on the web once browsers learned variable fonts.

  1. 1959

    Title sequences

    Saul Bass designs the opening titles of North by Northwest, with credits sliding along the lines of a building.

  2. 1995

    Nervous type

    Kyle Cooper's scratchy, jittering title sequence for Se7en makes kinetic type famous again.

  3. 2016

    Variable fonts

    Font makers announce OpenType variable fonts, where one file holds a whole range of widths and weights.

  4. 2023

    Scroll-driven CSS

    Browsers start supporting scroll-driven animations, letting type react to scrolling without JavaScript.

Prompt it

A ready prompt for AI design and coding tools. It names exact tokens and bans the usual defaults, so the output keeps this style's point of view.

Design a responsive landing page for an electronic music festival in an authentic Kinetic Typography style.

Palette: Black #0D0D0D, Charcoal #161616, Acid lime #C6FF00, Signal red #FF3D00, White #F2F2F2.
Typography: Anybody variable font (width 50 to 150, weight 100 to 900) for all display type in uppercase, Hanken Grotesk for body.
Layout: Full-height hero with one giant word whose letters animate width and weight in a staggered wave, a short intro, two buttons and a scrolling ticker strip below.
Signature details: Black background, white text, acid lime #C6FF00 accent and signal red #FF3D00. Type fills the width. Hover widens button labels using font-variation-settings.
Components: Pill buttons whose text stretches on hover, cards whose titles widen on hover, narrow uppercase badges and tabs.
Motion: Staggered letter waves, width and weight animations, a slow ticker. Everything respects prefers-reduced-motion.
Avoid: animated body text, many colours, stock images, fast flicker, motion without a pause option.
Do not fall back on generic AI defaults: no centered hero with a gradient blob, no identical rounded cards with soft grey shadows, no purple-to-blue gradients, no emoji icons, unless this style explicitly calls for them.
Accessibility: body text contrast of at least 4.5:1, visible keyboard focus on every control, labels on all form fields, and respect prefers-reduced-motion.
Deliver one self-contained HTML file with CSS variables for every color, font, radius and shadow token.

Common mistakes

Where this style usually goes wrong, and how to keep it honest.

Motion sickness

Large moving text can make people feel ill. Respect reduced motion and keep loops slow.

Unreadable words

Animate display words only. Body text should never move.

Heavy fonts

Variable fonts can be large files. Load only the axes you use.

Constant motion

If everything moves all the time, nothing stands out. Animate on purpose.

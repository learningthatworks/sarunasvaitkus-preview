Dithering
1-bit

Every shade on this page is made from only two colours. Tiny patterns of black and white dots trick the eye into seeing grey, shadows and curves.

Open the kit Copy the prompt

128 × 128 px · 869 bytes

What defines it

Dithering creates the illusion of many shades using only a few colours. On the web it gives images a retro, printed texture and can make them very light.

Two colours, many tones

Density of dots creates the shade. More black dots read as darker grey.

Visible pattern

Ordered dithering leaves a neat cross-hatched grid, while error diffusion looks like grain.

Crisp scaling

Images scale up with pixelated rendering, so each dot stays sharp instead of blurring.

One tint on top

A single accent colour can be layered over black and white with CSS blend modes.

Where it came from

Dithering was invented to squeeze images into limited screens and printers. Today people use it because they like the look.

  1. 1973

    Ordered dither

    Bryce Bayer at Kodak publishes the ordered dither matrix used for the patterns on this page.

  2. 1976

    Error diffusion

    Robert Floyd and Louis Steinberg publish a method that spreads rounding errors to neighbouring pixels, giving a grainy look.

  3. 1984

    1-bit desktops

    Early personal computers with black and white screens use dither patterns for every grey in the interface.

  4. 2018

    A 1-bit hit

    Return of the Obra Dinn, a mystery game by Lucas Pope, wins acclaim for its entirely dithered visuals.

  5. 2018

    Solar web

    Low-tech Magazine launches a solar-powered website that dithers its images to save energy.

Motion study

The light source circles the sphere and the dot pattern recalculates every frame. The only thing that changes is which dots are black.

Prompt it

A ready prompt for AI design and coding tools. It names exact tokens and bans the usual defaults, so the output keeps this style's point of view.

Design a responsive landing page for a slow-web magazine about repair and low technology in an authentic Dithering / 1-bit style.

Palette: Paper #F2F0E9, Ink #111111, Mid paper #E4E1D6, Signal orange #FF4F00.
Typography: Martian Mono 800 for headings and labels, Public Sans for body.
Layout: Two-column hero: headline with one word on a signal-orange block, a dithered gradient strip beneath, and a large dithered image tinted orange with CSS blend modes on the right.
Signature details: Only two colours (#111 and #F2F0E9) plus one orange tint. Ordered 8×8 Bayer dithering on images, image-rendering: pixelated, checkerboard dot shadows instead of blur.
Components: Square buttons that fill with a checkerboard on hover, cards with dotted offset shadows, dithered progress track, tables with a dotted header.
Motion: A live canvas that re-dithers a sphere as the light moves. No smooth gradients anywhere.
Avoid: gradients, blur, rounded corners, dithered text or charts, more than one accent colour.
Do not fall back on generic AI defaults: no centered hero with a gradient blob, no identical rounded cards with soft grey shadows, no purple-to-blue gradients, no emoji icons, unless this style explicitly calls for them.
Accessibility: body text contrast of at least 4.5:1, visible keyboard focus on every control, labels on all form fields, and respect prefers-reduced-motion.
Deliver one self-contained HTML file with CSS variables for every color, font, radius and shadow token.

Common mistakes

Where this style usually goes wrong, and how to keep it honest.

Unreadable charts

Dithering destroys thin lines and small text inside images. Keep charts in solid colour.

Smoothing ruins it

Browsers blur scaled images by default. Always set image-rendering: pixelated.

Pattern on text

Never put body text directly over a dither pattern. Use a solid panel.

Colour loses meaning

If colour carries information, dithering can erase it. Offer the original when it matters.

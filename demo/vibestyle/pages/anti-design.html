What defines it

Anti-design is a deliberate rejection of good taste and polish. It uses ugliness, chaos and default settings as a statement against sameness.

Broken grids

Blocks overlap, tilt and crash into each other instead of sitting in neat rows.

Default everything

System fonts, blue underlined links and raw form controls, used on purpose.

Clashing colours

Pure RGB colours like acid yellow, magenta and blue fight for attention.

Cropped giant type

Words so large they run off the screen, readable only in pieces.

Where it came from

Anti-design comes back whenever design becomes too polished and predictable.

  1. 1966

    Radical design

    Italian groups like Archizoom and Superstudio start an Anti-Design movement against tasteful modernism.

  2. 1990s

    Grunge typography

    Magazine designers break every rule of legibility, making disorder a style.

  3. 2010s

    Web brutalism

    Artists and studios build deliberately raw websites that reject templates.

  4. 2020s

    Anti-design revival

    Fashion brands, musicians and Gen Z portfolios embrace chaotic, ugly-on-purpose design.

Motion study

Anti-design motion is jerky and unpredictable. Words jump around in stepped moves instead of smooth animation.

Prompt it

A ready prompt for AI design and coding tools. It names exact tokens and bans the usual defaults, so the output keeps this style's point of view.

Design a responsive landing page for an experimental record label in an authentic Anti-design style.

Palette: White #FFFFFF, Acid yellow #FFFF00, Link blue #0000FF, Magenta #FF00AA, Toxic green #00FF66, Red #FF0000, Black #000000.
Typography: Tinos (Times style) for giant headlines, Arimo (Arial style) for body, Cousine (Courier style) for labels and buttons.
Layout: A giant headline cropped off the right edge, a tilted blue marquee band across the hero, sticky-note text blocks overlapping it, and a rotated magenta sticker saying NOT A TEMPLATE.
Signature details: Pure RGB colours (yellow, blue, magenta, green, red), 2px black borders, rotated and overlapping blocks, blue underlined links, crosshair cursor.
Components: Underlined monospace buttons that tilt and turn red on hover, rotated cards with different backgrounds, yellow tilted alerts.
Motion: Stepped, jerky jumps using steps() easing, a scrolling marquee.
Avoid: hidden navigation, unreadable body text, flashing colours, polished gradients, smooth easing.
Do not fall back on generic AI defaults: no centered hero with a gradient blob, no identical rounded cards with soft grey shadows, no purple-to-blue gradients, no emoji icons, unless this style explicitly calls for them.
Accessibility: body text contrast of at least 4.5:1, visible keyboard focus on every control, labels on all form fields, and respect prefers-reduced-motion.
Deliver one self-contained HTML file with CSS variables for every color, font, radius and shadow token.

Common mistakes

Where this style usually goes wrong, and how to keep it honest.

Unusable chaos

Breaking layout is fine. Breaking navigation, contrast or focus states is not.

Hidden content

Overlaps must never cover important text or buttons.

Flashing colours

Rapid colour flashing can trigger seizures. Keep motion stepped but slow.

Chaos without idea

Random ugliness is just ugly. Anti-design needs a point of view.
